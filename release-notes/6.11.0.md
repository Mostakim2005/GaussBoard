# GaussBoard v6.11.0

## Pentagram Ecosystem Interop, Dual SPICE Engine, RAG Manager & Audit Hardening

GaussBoard v6.11.0 completes Phases 1–4 of the Pentagram Ecosystem integration alongside dual SPICE circuit simulation, Anki deduplication, headless JSON CLI export, and six sequential security/stability audit patches.

### Highlights
- **Pentagram Ecosystem & RAG Manager**:
  - Added RAG Manager ingest (`rag-bridge.cjs`), canonical `xref_id` linking, and DeepTutor actions (`pentagram-sync.js`).
  - Added Pentagram health drawer, ecosystem bridges (`global-resources.cjs`, `cas-sympy.cjs`, `media-bridge.cjs`, `mermaid-bridge.cjs`, `triarchy-bridge.cjs`), and deep links with full 7-locale i18n parity.
  - Purged redundant in-tree vendor dependencies in favor of shared `%LOCALAPPDATA%\SharedLibraries` and `ecosystem-registry.json` resolution.
- **Circuit Workbench & Anki**:
  - Added dual SPICE simulation engine (`spice-engine.js` and `spice-bridge.cjs`) integrated into the Circuit Workbench.
  - Added Anki card deduplication, media wiring, and headless JSON CLI export (`cli-export.cjs`).
- **Security, Stability & Accessibility**:
  - Applied six sequential audit patches covering security hardening, parser safety, UI/modal accessibility, and test isolation.
