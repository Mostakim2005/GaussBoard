# GaussBoard v6.9.2

## Forked and rebranded

GaussBoard is a fork of [GazBoard](https://github.com/fahim9778/GazBoard) by MD. Fakhruddin Gazzali (theBoringCodes), maintained by Kazi S. Mostakim. The product name is GaussBoard; the internal app identity, storage folder and `.gazboard` file format stay unchanged so that upstream changes and existing boards keep working.

- Repointed the update feed, release links, font sources and Android update check from the upstream repository to this fork, which fixes update checks that were pointing at a repository that does not exist.
- Removed the Linux, macOS and web release jobs. Releases from this fork now build two Windows artifacts: the portable `.exe` and the installer `.exe`. Android is built separately by `android-release.yml`, which needs a signing keystore.

## Senior hardening audit (P0 + P1)

74 findings logged, 68 fixed, with the remaining items documented as known limitations.

- **Split workspace**: save, focus and editor corrections.
- **Inking**: eraser-fragment timestamp preservation.
- **Replay**: ghost and cover partitioning.
- **Study tools**: study-runner cover state and freehand-tape attachment.
- **Circuits**: DOL contactor latch and a fully wired Forward-Reverse preset; diode forward drop, driver-node propagation, DMM continuity and audio throttles.
- **Video export**: WebM-with-audio as the default export, plus an MP4 no-sound notice.
- **Markdown**: quadratic-regex denial-of-service fixed and recursion limits added; KaTeX is now loaded on demand.
- **Grapher**: domain, asymptote and zoom safety.
- **Tabs**: undo cache, duplicate and session dialogs.
- **Geometry**: degenerate orthogonal arrowheads.
- **i18n**: 100% parity across 7 locales (2,245 keys).
