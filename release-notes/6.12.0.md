# GaussBoard v6.12.0

## SharedLibraries Offload, Tablet Bezier Splines, Drafting Tools & Whiteout Mask

GaussBoard v6.12.0 introduces non-destructive Whiteout masking, Huion/tablet-aware Editable Bezier Splines, a Compass drafting tool, Vertical Space insertion, Grid & Rotation snapping, deterministic `Rough.js` sketchy shapes, Pane-Aware split-workspace commands, and on-demand SharedLibraries management while shrinking the core package to `10.77 MB`.

### Highlights
- **SharedLibraries Offload & On-Demand Downloader**:
  - Moved heavy duplicate optional bundles (`Mermaid`, `Chart.js`, `pdf-lib`) out of the core bundle (`src/vendor/`) into `%LOCALAPPDATA%\SharedLibraries` (Desktop) and browser `CacheStorage` (`gazboard-libs-v1` on PWA), reducing the core PWA footprint to `10.77 MB` under a relaxed budget.
  - Added startup and on-demand availability checks with an interactive HTTPS-allowlisted Download modal (`electron/library-manager.cjs`, `src/js/ui/library-inspector.js`) and `"Don't ask on startup"` preference.
- **Drafting, Sketchy Shapes & Tablet Inking**:
  - **Editable Bezier Splines**: Interactive anchor knots and cubic tangent handles with SVG export plus a floating Finish/Close Loop/Undo Knot HUD pill using pointer-type auto-detection (`auto` uses Pill-Only for stylus/Huion tablets and Double-Click + Pill for mouse).
  - **Whiteout / Masking Eraser**: Dynamic paper-matched opaque masking strokes omitted in transparent PNG exports, excluded from Hold-to-Shape snapping, and erasable while preserving `p.t` timestamps (`TRAP 2`).
  - **Compass Drafting Tool**: Wheel compass in the Ruler menu with pivot handle, adjustable radius arm, circumference snapping preserving `p.t`, and radial scale markings.
  - **Vertical Space & Precision Snapping**: Horizontal divider shifting lower objects and expanding blank/notebook page height (blocking locked PDF pages), toggleable Grid Snap, and Always-On 15° Rotation Snap (`Alt` bypass + live degree badge).
  - **Rough.js Sketchy Shapes**: Deterministic `roughSeed` hand-drawn shapes with Zoom LOD culling (`camZ < 0.35`) and SVG export parity.
- **Split Workspace & Documentation**:
  - **Pane-Aware Command Dispatcher**: Delete, Copy, Cut, Duplicate, Paste, Select All, Group/Ungroup, and Z-order shortcuts now target whichever Split Workspace pane holds focus.
  - Updated living docs and attributions (`THIRD_PARTY_NOTICES.md` adding Rough.js `MIT`), keeping the Multi-Layer Stack explicitly paused.
