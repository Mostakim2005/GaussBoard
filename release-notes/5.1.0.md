# GazBoard v5.1.0

## Split boards and excerpts

- Copy a selection as a visual excerpt, then paste or drag it into another board or split pane.
- Excerpt images link back to their original board, page and area. Select the excerpt and choose **Open source excerpt**, or Ctrl-click the image.
- The split workspace routes paste to the pane under the pointer and accepts excerpt drops while keeping each board's edits independent.

## Markdown and links

- Link directly to Markdown headings or block IDs, including local links such as `[[#Heading]]` and `[[#^block-id]]`.
- Added Obsidian-style highlights, subscript/superscript, footnotes, hidden comments, tilde fences and hidden block-ID markers.
- Existing tables, task lists, callouts, math, tags, aliases and Markdown cards continue to work.

See [`RELEASE-5.1.0.md`](../docs/releases/RELEASE-5.1.0.md) for details, limitations and verification results.
