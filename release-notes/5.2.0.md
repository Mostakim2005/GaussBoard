# GazBoard v5.2.0

## Toolbar and Menu Modernization

- Restored `.menu-item` class and added click event delegation across menu cards, ensuring smooth click and touch activation across desktop, tablet and mobile form factors.
- Resolved popover menu element traversal for automated testing and touch navigation.

## Inking, Text & Markdown Rendering Refinements

- Disambiguated plain text boxes from explicit Markdown card windows in both canvas rendering and SVG vector exports.
- Plain text objects maintain a transparent background without unexpected card borders or badges while typing.
- Inline LaTeX math formulas in plain text objects export cleanly with full SVG equation rendering.

## Offline PWA Precache Synchronization

- Added all post-4.8.1 core modules (`excerpts.js`, `markdown.js`, `replay-clock.js`, `pagemargin-dialog.js`, `properties-dialog.js`) to the Service Worker precache manifest for complete offline reliability.

## Automated Verification

- Increased test timeout tolerance in Electron feature test runners to ensure stability under heavy system load.
- Maintained 100% translation key parity across all 7 supported locales.

See [`RELEASE-5.2.0.md`](../docs/releases/RELEASE-5.2.0.md) for details, limitations and verification results.
