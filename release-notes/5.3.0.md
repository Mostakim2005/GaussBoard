# GazBoard v5.3.0

## Deep Codebase Audit & Root-Cause Fixes

- Fixed SVG `<foreignObject>` XHTML serialization in `buildMarkdownSvgDataUri` where post-render regex replacements corrupted `xmlns` attributes, restoring canvas Markdown card rendering.
- Fixed Split Study Workspace lifecycle, surface memory cleanup on close, left-pane asset resolution/externalization, left-pane `Store` subscription for dirty/autosave state, and `swapPanes()` camera and audio track preservation.
- Fixed `.gazboard` single-board ZIP export and import so boards with recorded or imported audio tracks bundle and extract their audio assets instead of writing unplayable JSON references.
- Fixed `Store.commit` transaction validation and converted audio recording, bookmark, connector arrowhead, and board-link thumbnail mutations into valid undoable store operations that trigger persistence.
- Fixed `ink.js` WeakMap cache thrashing during live audio replay and dual-pass rendering by storing up to 6 engine/width variants per stroke point array and removing per-stroke `ctx.filter` state switches in Spotlight replay mode.
- Fixed `perfectFreehand` engine selection in `runPath`, stylus `tiltX`/`tiltY` nib angle calculation in `calligraphyPath`, and `p.t` timestamp preservation on freehand Study Tape strokes.

## Lateral Features & Quality-of-Life Improvements

- **Hold-to-Shape Recognition (`holdToShape`, default ON)**: Pausing the pen still for 420 ms at the end of a freehand stroke snaps lines, rectangles, ellipses, triangles, diamonds, and arrows into clean shapes even when global Ink-to-Shape is off.
- **Skip Silence During Audio Replay (`replaySkipSilence`, default OFF)**: Automatically fast-forwards across silent dead-air gaps longer than 2.0 seconds between recorded stroke clusters while stopping at bookmarks.
- **Tap Stroke to Seek Audio (`tapStrokeToSeek`, default ON)**: Tapping a recorded stroke in Reading Mode or with the Select tool while AudioBar is open jumps playback to that stroke's start timestamp (`t0`).
- **Synchronized Split-View Scrolling (`splitSyncScroll`, default OFF)**: Locks camera zoom and pan deltas across the left reference board and right workspace pane for side-by-side comparison.
- **Auto-Dim Floating Toolbars While Inking (`autoDimBarsWhileInking`, default ON)**: Fades floating HUDs (`#toolbar`, `#replayBar`, `#audioBar`, `#zoombar`, `#pagebar`) to 20% opacity with `pointer-events: none` during active pen strokes so chrome never intercepts mid-stroke pen movement.
