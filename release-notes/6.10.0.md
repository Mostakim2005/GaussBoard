# GaussBoard v6.10.0

## Media, UI Polish, Ink Hardening & Security Overhaul

GaussBoard v6.10.0 delivers major multimedia enhancements, canvas tool refinements, security hardening, and desktop runtime stability.

### Highlights
- **Media & Subtitles**:
  - Integrated subtitles directly into \VideoPlayerDialog\ with Anki-importable TSV export.
  - Inlined video bookmarks, preserved excerpt paste metadata, and fixed cropped image aspect ratio handling.
  - Allowed Electron \pp://\ microphone permissions and HTTP 206 asset range streaming.
- **UI & Workspace Enhancements**:
  - Theme-safe \PdfSidebarDrawer\, ChromeManager left-drawer exclusion, and Zen Mode toggle (\F10\ / \Ctrl+\\\).
  - Markdown toolbar SVG leak/wrap fixes and improved Study Tape contrast.
  - Smooth PDF eraser ring layer, neon pen hardening, erase-shapes toggle, and pen glow.
- **Security & Desktop Runtime**:
  - Escaped Dataview column headers and ribbon HTML interpolations against injection.
  - Replaced unsupported \window.prompt()\ calls with async \pp.askText()\ modal dialogs.
  - Cleaned unreferenced vendor precache entries and added audit regression test coverage.
