# GazBoard v5.0.0

## Replay and camera

- Added Live reveal, Spotlight and Static audio replay display modes. They work on the live board and in single or stitched video exports.
- Made video export respect the existing Ghost/Hidden Preview setting, matching live playback.
- Kept replay appearance independent from Reading/Writing mode and made replay controls available with a single recording.
- Smoothed center-follow camera movement over a longer interval and prevented pause/resume or delayed frames from causing sudden jumps.
- Reused a bounded per-track stroke index to reduce repeat full-board lookup work during replay and export.
- Protected end/replay and recording-switch behavior with a new lifecycle regression test.

## Input reliability

- Normalized scratch-out gesture classification across different pointer report rates without changing ink samples.
- Finalized in-progress gestures and released pointer capture when the application window loses focus.
- Closed recording-menu pointer listeners reliably, including the delayed-attachment edge case.
