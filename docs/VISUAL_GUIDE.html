GaussBoard 6.9.2 Visual Dashboard

Offline whiteboard and STEM workstation for EE students. Original GazBoard heritage by theBoringCodes, GaussBoard line by Kazi S. Mostakim. Source: Opencode/GazBoard v6.9.2.

[FEATURE: Infinite-Canvas-Pen-Inking] Active Feature
1-Line Summary: Infinite pan/zoom canvas where the stylus inks and the mouse points, with pressure-sensitive pen and highlighter that stay exactly as drawn.

User Intention: Draw on an infinite canvas without losing work, with sticky colors, edge auto-pan, connection to figures, and 8 paper colors plus patterns.

Code Anchor: src/js/core/ink.js → createInkEngine / pressure
[FEATURE: Audio-Ink-Replay] Active Feature
1-Line Summary: Record voice while writing, then replay the drawing in time with the audio using the waveform scrubber and bookmarks.

User Intention: Lectures play back stroke-by-stroke in timestamp order with live reveal, spotlight, static mode, seeking, and camera follow.

Code Anchor: src/js/core/store.js → checkpoint / applyRemote
[FEATURE: Split-Workspace] Active Feature
1-Line Summary: Two independent side-by-side boards with separate cameras, stores, undo stacks, and text editors for textbook plus notes work.

User Intention: Read on one side, write on the other, with chained saves, focus lease, and no silent loss on switch.

Code Anchor: src/js/ui/split-workspace.js → flushLeftBoard / openBoardInSplit
[FEATURE: Document-Import-Pages] Active Feature
1-Line Summary: Drag in PDF, Word, PowerPoint, and spreadsheet files, pick pages and layout, then annotate each page independently.

User Intention: Bring lecture slides onto the board, choose quality, and annotate pages that stay movable and exportable while ink erases separately.

Code Anchor: src/js/importers/pdf.js → rasterizePdf / soffice.js
[FEATURE: Circuit-Sim-EE-Workbench] Active Feature
1-Line Summary: Headless MNA circuit engine with semiconductors, 555, DOL and Forward-Reverse presets that actually latch.

User Intention: Wire circuits that behave correctly with diode drops, driver outputs, DMM continuity, and BOM export.

Code Anchor: src/js/core/circuit-sim.js → solveMNA / armatureLatch
[FEATURE: LAN-Handoff-Sync] Active Feature
1-Line Summary: Device-to-device board handoff on the same Wi-Fi with X25519 and AES-256-GCM, one-time codes, and firewall self-checks.

User Intention: Send boards without cloud or accounts, with Just-for-now versus Remember pairing and explicit accept/keep-both/replace.

Code Anchor: sync/protocol.js → createPairingCode / sealMessage
[FEATURE: Media-Export] Active Feature
1-Line Summary: Export to PNG at 2x, editable SVG, paginated PDF, and stitched WebM with audio by default plus MP4 with no-sound notice.

User Intention: Share work anywhere with correct pagination, real vector text, and no silent video loss.

Code Anchor: src/js/export-video.js → exportWebM / exportMP4

[TRAP: Pt-Timestamp-Stripping] DO NOT TOUCH
Strict Rule: Never rebuild stroke points without preserving p.t, or audio replay loses millisecond sync.

What Breaks If You Touch It: Replay binary-searches ascending p.t; without it erased fragments replay at the wrong time or never, and smoothing breaks lecture playback.

Protected Anchor: src/js/core/ink.js → preserveTime
[TRAP: Replay-Overlay-Partitioning] DO NOT TOUCH
Strict Rule: Base canvas must exclude active audio strokes; replay strokes live only in the dynamic overlay pass.

What Breaks If You Touch It: Baking replay ink freezes the animation, overpainting covers leaks answers, and ghost allocation stalls recordings.

Protected Anchor: src/js/core/surface.js → drawFrozen / drawReplaySession
[TRAP: Dual-Pane-Cross-Contamination] DO NOT TOUCH
Strict Rule: Split panes must use separate stores, cameras, editors, and undo paths, or edits land on the wrong board.

What Breaks If You Touch It: Shared editors and after-await IDs cause autosave races, wrong-pane undo, and silent loss.

Protected Anchor: src/js/ui/split-workspace.js → activePane / flushLeftBoard
[TRAP: Untrusted-Url-And-Path] DO NOT TOUCH
Strict Rule: Only https/http web URLs and whitelisted release paths may reach the OS; raw board text is never HTML or filesystem paths.

What Breaks If You Touch It: file: and javascript: URLs plus dot-dot paths escape the sandbox, and picker markup injection enables self-XSS.

Protected Anchor: src/js/platform/security.cjs → safeExternalUrl
[TRAP: Bench-Topology] DO NOT TOUCH
Strict Rule: Drivers mutate nodes in place and armature latches from completed potentials, or downstream LEDs freeze.

What Breaks If You Touch It: Object replacement strands nodes, half-propagated latching drops the coil, and diode caps distort bridge voltage.

Protected Anchor: src/js/core/circuit-sim.js → solveMNA / armatureLatch
